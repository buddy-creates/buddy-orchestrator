# PRD Template

## Title

Short product-facing name.

## Problem

What painful business problem are we solving?

## Target User

Who uses this?

Examples:

- Founder/operator
- Bookkeeper
- Sales lead
- Customer support rep
- Ops manager

## Buyer

Who pays for this?

## Current Workflow

How does the user do this today?

## Desired Workflow

What should be easier after this ships?

## User Stories

- As a [user], I want [capability], so that [business outcome].

## Requirements

### Functional Requirements

- Requirement 1
- Requirement 2

### Non-Functional Requirements

- Performance
- Reliability
- Privacy
- Security
- Auditability
- Maintainability

## Acceptance Criteria

Use observable behavior:

- Given [state], when [action], then [observable behavior].

## Data Model

Entities, fields, constraints, and ownership.

## Permissions

Who can read/write/delete/export?

## External Integrations

List all external services and required credentials.

## Safety Risks

What can go wrong?

## Edge Cases

- Empty state
- Bad input
- Slow external API
- Duplicate data
- Partial failure
- Permission denied
- Retry behavior

## Telemetry

What should we log or measure?

## Non-Goals

What are we explicitly not building?

## Rollout Plan

- Local only
- Internal test
- Staging
- Production
- Rollback

## Open Questions

List unresolved questions.
